# 🚛 Fuel Tracker Bot — Інструкція налаштування

## Що робить цей бот

Водій пише `/start` → обирає своє авто зі списку → вводить пробіг → надсилає фото спідометра → дані автоматично зберігаються в Google Sheets.

---

## Крок 1 — Підготовка Google Sheets

### 1.1 Створіть нову Google Таблицю
Відкрийте [sheets.google.com](https://sheets.google.com) → "Нова таблиця".

Назвіть її: **Fuel Tracker**.

Запишіть ID таблиці з URL:
```
https://docs.google.com/spreadsheets/d/ВАШ_ID_ТУТ/edit
```

### 1.2 Створіть два листи в таблиці:

**Лист 1: `Картки_Авто`** — заповніть вручну:

| Держ. номер | Картка E100  | Водій             |
|-------------|--------------|-------------------|
| WPI1751C    | 95620011     | KOLTAKOV OLEKSII  |
| WPI6613E    | 95620037     | KHELCHYK HENADII  |
| WPI8610H    | 95620052     | STRELA YEVHENII   |
| ...         | ...          | ...               |

**Лист 2: `Пробіги`** — залиште порожнім, бот заповнить автоматично.

---

## Крок 2 — Google Service Account

### 2.1 Створіть проєкт в Google Cloud
1. Відкрийте [console.cloud.google.com](https://console.cloud.google.com)
2. "Новий проєкт" → назва: `fuel-tracker`
3. Увімкніть API:
   - **Google Sheets API**
   - **Google Drive API**

### 2.2 Створіть Service Account
1. IAM & Admin → Service Accounts → "Create Service Account"
2. Назва: `fuel-bot`
3. Ролі: "Editor"
4. Створіть ключ → JSON → завантажте файл

### 2.3 Дайте доступ до таблиці
Відкрийте завантажений JSON, знайдіть поле `"client_email"`.

Відкрийте вашу Google Таблицю → "Поділитися" → вставте цей email → роль "Редактор".

## Крок 3 — Telegram Bot Token

У вас вже є токен від @BotFather. Якщо потрібен новий:
1. Напишіть @BotFather в Telegram
2. `/newbot` → дайте назву → отримайте токен виду `7123456789:AAF...`

---

## Крок 4 — Деплой на Railway (безкоштовно)

### 4.1 Підготуйте репозиторій
1. Зареєструйтесь на [github.com](https://github.com)
2. Створіть новий репозиторій: `fuel-bot`
3. Завантажте файли: `bot.py`, `sheets.py`, `requirements.txt`, `Procfile`

### 4.2 Деплой на Railway
1. Відкрийте [railway.app](https://railway.app) → Login with GitHub
2. "New Project" → "Deploy from GitHub repo" → оберіть `fuel-bot`
3. Railway автоматично визначить Python і встановить залежності

### 4.3 Налаштуйте змінні середовища
В Railway → ваш проєкт → "Variables" → додайте:

| Змінна                   | Значення                              |
|--------------------------|---------------------------------------|
| `BOT_TOKEN`              | `7123456789:AAF...` (ваш токен)       |
| `SPREADSHEET_ID`         | ID вашої Google Таблиці               |
| `GOOGLE_CREDENTIALS_JSON`| Вміст всього JSON файлу service account |

> ⚠️ `GOOGLE_CREDENTIALS_JSON` — скопіюйте весь вміст JSON файлу в одну змінну.

### 4.4 Запуск
Після додавання змінних Railway перезапустить бота. Перейдіть в "Logs" — повинно з'явитися:
```
Bot started...
```

## Крок 5 — Перевірка

1. Знайдіть бота в Telegram (за username який дав BotFather)
2. Напишіть `/start`
3. Оберіть авто → введіть пробіг → надішліть фото
4. Перевірте Google Sheets — лист "Пробіги"

## Наступний крок — E100 API

Після того як бот запрацює — підключимо автоматичну вигрузку транзакцій з E100 в ту ж таблицю. Тоді матимемо:
- Пробіг (з бота) + Літри пального (з E100) = **Розхід л/100км** автоматично.
